## Deskripsi Peran
Project Manager bertanggung jawab mengatur jalannya kolaborasi tim di GitHub dan memastikan setiap anggota dapat berkontribusi pada repository yang sama.

## Kontribusi
- Membuat repository kelompok `software-development-team-kelompok 5` dengan visibilitas public.
- Menambahkan anggota tim (Front-End dan Back-End Developer) sebagai collaborator.
- Membuat dan mengisi `README.md` yang memuat nama kelompok, nama anggota, mata kuliah, dan deskripsi repository.
- Mengoordinasikan pembagian peran dan alur kerja tim (clone, branch, commit, push, pull request, review, merge).
- Melakukan review dan merge Pull Request dari anggota lain.
